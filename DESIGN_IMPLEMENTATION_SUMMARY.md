## 🎨 Color System Used

```

```

### Component Colors
- **Indigo**: Primary actions, main headers, important elements
- **Purple**: Secondary elements, gradients
- **Pink**: Accents, highlights
- **Cyan**: Information, insights
- **Green**: Success, positive status
- **Orange**: Warnings, secondary actions
- **Red**: Danger, destructive actions
